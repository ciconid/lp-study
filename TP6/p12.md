# Mecanismos de pasaje de parámetros en Java y Pascal

## Java

Java utiliza **pasaje por valor** (*pass by value*) en todos los casos.

- Si se pasa un tipo primitivo (`int`, `double`, `boolean`, etc.), se copia el valor.
- Si se pasa un objeto, se copia la **referencia** al objeto, no el objeto en sí.

### Ejemplo con tipo primitivo

```java
public static void cambiar(int x) {
    x = 20;
}

public static void main(String[] args) {
    int a = 10;
    cambiar(a);
    System.out.println(a);
}
```

Salida:

```
10
```

La variable `a` no cambia porque el método recibe una copia de su valor.

### Ejemplo con objetos

```java
class Persona {
    String nombre;
}

public static void cambiarNombre(Persona p) {
    p.nombre = "Juan";
}

public static void main(String[] args) {
    Persona persona = new Persona();
    persona.nombre = "Pedro";

    cambiarNombre(persona);

    System.out.println(persona.nombre);
}
```

Salida:

```
Juan
```

El método recibe una copia de la referencia, pero ambas referencias apuntan al mismo objeto, por lo que sus atributos pueden modificarse.

## Pascal

Pascal admite dos mecanismos principales.

### 1. Pasaje por valor

Se copia el valor del parámetro actual al parámetro formal.

```pascal
procedure Cambiar(x: Integer);
begin
    x := 20;
end;

var
    a: Integer;
begin
    a := 10;
    Cambiar(a);
end.
```

Después de la llamada, `a` sigue valiendo `10`.

### 2. Pasaje por referencia (`var`)

El parámetro formal se convierte en un alias del parámetro actual.

```pascal
procedure Cambiar(var x: Integer);
begin
    x := 20;
end;

var
    a: Integer;
begin
    a := 10;
    Cambiar(a);
end.
```

Después de la llamada, `a` vale `20`.

---

## Diferencias principales

| Característica | Java | Pascal |
|---------------|-------|---------|
| Pasaje por valor | Sí | Sí |
| Pasaje por referencia explícito | No | Sí (`var`) |
| Posibilidad de modificar directamente una variable primitiva del llamador | No | Sí, usando `var` |
| Objetos/Estructuras | Se copia la referencia | Puede pasarse por valor o por referencia |

## Ejemplo comparativo

### Java

```java
void incrementar(int x) {
    x++;
}
```

```java
int a = 5;
incrementar(a);
// a sigue valiendo 5
```

### Pascal

```pascal
procedure Incrementar(var x: Integer);
begin
    x := x + 1;
end;
```

```pascal
a := 5;
Incrementar(a);
// a vale 6
```

## Conclusión

La diferencia fundamental es que **Java siempre pasa argumentos por valor**, mientras que **Pascal permite elegir entre pasaje por valor y pasaje por referencia mediante la palabra clave `var`**.
