## Expresiones Mixtas

**Pascal** tiene un sistema de tipos más duro.

En Pascal, mezclar tipos en una expresión (por ejemplo `integer` con `real`) está muy restringido — el compilador lo rechaza o exige conversiones explícitas en la mayoría de los casos.

En Python, una expresión como `3 + 2.5` es perfectamente válida — el intérprete aplica coerción implícita y promueve el entero a float automáticamente.

---

## Declaraciones de Tipo

Acá también **Pascal** es más duro, pero por una razón diferente.

Pascal exige que **toda variable sea declarada explícitamente** con su tipo antes de usarse. El compilador verifica en tiempo de compilación que cada uso sea consistente con la declaración.

```pascal
var
  x : integer;
  y : real;
```

Python no tiene declaraciones de tipo obligatorias. Una variable toma el tipo del valor que se le asigna en el momento, y puede cambiar de tipo durante la ejecución:

```python
x = 5       # int
x = "hola"  # ahora es str, sin error
```

---

## Resumen

| Criterio | Pascal | Python |
|---|---|---|
| Expresiones mixtas | Duro — pocas coerciones implícitas | Blando — coerciones automáticas frecuentes |
| Declaraciones de tipo | Duro — obligatorias y estáticas | Blando — inexistentes o opcionales (hints) |
| Momento de verificación | Compilación | Ejecución |

Pascal es más duro en ambos aspectos. La diferencia de fondo es que Pascal es **estáticamente tipado y fuertemente tipado**, mientras que Python es **dinámicamente tipado** y relativamente permisivo con las conversiones implícitas.
